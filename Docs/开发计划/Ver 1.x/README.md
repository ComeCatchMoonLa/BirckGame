## 2. 实现时怎么用需求

当试卷刷题，不要为 1.x 再开技术设计 / 接口设计。

1. 读本版在 [需求.md](需求.md) 里对应编号。
2. 变体：只改写明的差；其余抄原作。
3. 新作：3～6 条规则不够细时，联网核对同名小品常识（2048 合并、扫雷数字等）。
4. 用现有 `SetConsole` / `SetPos` / `PumpFrame` / `DueLogicTick` 或 `TakeLogicSteps` / `QuitToLauncher` / `SubmitScore`。
5. 一号一个 exe，CMake `add_legacy_game`，注册表填 exe 名和窗口列行。不抽游戏基类，不预建空文件夹。

引擎仍以 0.x 已拍接口为准。某款真卡住再开 0.6+，不预列双缓冲。
