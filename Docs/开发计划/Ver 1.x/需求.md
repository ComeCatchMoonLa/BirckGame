# 1.x 需求试卷

> **结论：一号一题。** 变体只写相对原作改什么；新作写目标、操作、胜负、计分。规则含糊时联网核对同名小品。共用约定见 [README.md](README.md)。

已实现原作（对照用，不在本卷）：1 俄罗斯方块 Pro、2 贪吃蛇 Pro、3 消除射击、4 填补射击、7 方块赛车、17 迷宫 One。局结更高分才 `SubmitScore`；Esc 回菜单。

## 1.1 蛇单人变体

相对 **贪吃蛇 Pro**（选图、Z 加速、每食物 +10）。

- **49 穿墙蛇**：出界从对边出现，不因撞墙死；撞自己仍死。
- **51 障碍蛇**：固定若干墙格，撞墙死（可沿用 Pro 地图或更简单的内置障碍）。
- **52 限时蛇**：开局倒计时（随 SPEED 缩放）；到时结束，分数为已吃食物分。
- **53 加速蛇**：每吃一个食物，逻辑步永久加快一档（仍受整机 SPEED 下限约束）；不要只靠 Z。
- **54 围墙蛇**：场地四周是实墙，不能穿；无 Pro 选图，一张空场即可。

## 1.2 方块易变体

相对 **俄罗斯方块 Pro**（整机 SPEED 下落、下键加速、消行计分、HUD 显示 SPEED）。本族 HUD 不显示 tick。

- **38 隐形方块**：当前块从出生到落点的前半段常显，后半段低频闪烁，落地锁定后稳定显示。
- **39 只出方形**：上键（小键盘上；NumLock 开时为 8）随机改变当前块形状。
- **42 四十行挑战**：一次消 1/2/3/4 行得 1/3/5/7 分，达到 30 分即胜。胜利居中显示 Win（与 Game Over 同宽、空格补齐）；计分越高越好。
- **44 无旋转方块**：每块仅可旋转 3 次，HUD 显示剩余次数。
- **47 宽场方块**：板宽 20 列，窗口列数跟着改。
- **48 窄场方块**：板宽 8 列，窗口列数跟着改。

## 1.3 方块规则变体

相对 **俄罗斯方块 Pro**。

- **36 镜像方块**：四向按键对调（左↔右、上↔下）；重力仍向下。HUD 写「方向对调」。
- **37 五格方块**：两种三连（I3、L3）加五种五连（I、T、L、Y、P）；板宽 15。
- **40 炸弹方块**：整块可成炸弹，概率 1/形状数；锁定后每格炸 3×3（含自己）。
- **43 垃圾行方块**：每隔若干拍从底部塞入一行带缺口的垃圾。
- **45 同色消行**：两种颜色（■/□）。同行连续同色格数超过列数一半则消该段（14 列即 ≥8）；一次锁定先消所有合格段，再让被消列的方块下坠填空，可连锁。每段 +1 分。每次完成消除，下一个方块必定是炸弹（锁定后每格炸 3×3）。
- **46 重力方块**：消行后上方块逐格掉落填空，可连锁。

## 1.4 射击 / 赛车变体

- **55 对向赛车**：相对 **方块赛车**，障碍/对向车从上方迎面来，碰撞即死；计分仍为存活拍。
- **56 加油赛车**：相对 **方块赛车**，油量随时间降，吃到油罐加满；油尽或出道即死。
- **63 双炮射击**：相对 **消除射击**，左右各一门，Z 同时或轮流发射。
- **64 限弹填补**：相对 **填补射击**，弹仓有上限，打完须等补充或捡弹。
- **65 护盾打蜂**：相对 **打蜜蜂（14）** 的玩法预期（底边射向上的蜂）；本号玩家有短暂护盾（Z 或自动回复）。若 14 尚未做，本号可先做「底边射击 + 护盾」，14 再补蜂群编队。

## 1.5 新小品

- **24 井字棋**：3×3；光标 + 空格落子；玩家先手，电脑随机或贪心占赢线；三连胜负；平局可重开。计分：胜 +1。借鉴：回合制，无需下落拍。
- **31 打地鼠**：若干洞循环冒头；方向或数字打当前洞；打中 +1，漏掉过多结束。节拍走 `TakeLogicSteps`。
- **87 汉诺塔**：三柱、三～五盘；方向选柱，空格拿/放；大压小非法；全到最右胜。计分：步数越低越好。
- **22 flappy bird**：侧视一格鸟；空格/上键跳，否则下落；穿过柱间隙 +1，撞柱或地结束。节拍走逻辑拍。
- **29 乒乓球**：竖屏或横屏一块挡板对一球；挡板只沿一边移动；漏球结束；反弹加分。借鉴寸步难行的球反射，但只有一块板。

## 1.6 2048 / 扫雷族

- **79 五格2048**：相对 19，棋盘 5×5。
- **33 扫雷**：9×9、约 10 雷（初级）；开格/插旗（可两键：空格开、Z 旗）；数字为邻雷数；踩雷负，全非雷格翻开胜。计分：胜为剩余秒或翻开格数。
- **80 中级扫雷**：相对 33，16×16、40 雷量级。
- **81 高级扫雷**：相对 33，更大盘（如 16×30、99 雷）；窗口要撑得住。

## 1.7 翻牌 / 连连看

- **32 连连看**：成对图案；两点用不超过三条直线（可沿空格走）连通则消；消完胜。计分：剩余时间或消除对数。
- **82 计时连连看**：相对 32，到时未清盘负。
- **34 记忆翻牌**：偶数张牌背面朝上；翻两张，相同则留下，否则扣回；全配完胜。计分：步数越低越好或用时。
- **85 计时翻牌**：相对 34，到时未配完负。

## 1.8 过河 / 接物 / 躲避

新实时族，网格 + 碰撞即可。

- **8 青蛙过河**：底边青蛙，上到对岸胜一程；车道有横向车，河有圆木（站木上才不掉水）；撞车/落水死。计分：成功次数。
- **11 接水果**：底边左右移动，接住落下物 +1，漏接过多结束。
- **57 双向过河**：相对 8，两岸都要往返，或同时有反向车流。
- **58 炸弹水果**：相对 11，部分落下物是炸弹，接到即死。
- **60 落石躲避**：玩家在底边或场内，石头落下，躲开；撞到死。计分：存活拍。
- **61 过马路**：类似 8 但只有车道、无河；到顶 +1 并回到底边。
- **62 接降落伞**：相对 11，接的是伞兵/伞包，左右飘不止竖直落。

## 1.9 打砖 / 弹球

- **9 碰撞弹球**：场内若干球互相撞并撞墙反射；玩家是可动挡板或可动块，被球碰到死。借鉴寸步难行，球之间也碰。
- **28 打砖块**：底边挡板反弹一球，打掉上方砖；球掉出底边失一命（三命）；砖打完胜。计分：砖分。
- **69 多球打砖**：相对 28，可同时多球（打到某砖分裂或开局多球）。
- **70 激光打砖**：相对 28，Z 发射直线激光消砖，球仍在或可弱化球。
- **72 多球弹球**：相对 9，球数量更多。

## 1.13 解谜

- **12 十滴水**：网格水滴，点一下加一滴，满则爆并向四向传；滴数有限，清盘胜。
- **16 数字魔方**：2D 表示的层旋转（如把数字转到目标面）；以「打乱后还原」为准，阶数 2 或 3。
- **18 数独**：9×9，光标填 1～9，冲突高亮；填满且合法胜。可给一道固定谜题，不必生成器。
- **77 六宫数独**：相对 18，6×6（宫 2×3）。
- **88 一笔画**：图上每边走一次且只一次；走完所有边胜。内置一两张图。
