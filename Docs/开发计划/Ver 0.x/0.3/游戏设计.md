# 0.3 游戏设计大纲：硬编码优化

> **草稿。** 在 0.2 节拍落地后再转正。只收拾已经添乱的重复，不借机重构。

## 交付目标

启动器与已实现游戏里，**正在造成双份真相或仍绕过引擎的硬编码**收掉一处。观感仍是同一台掌机，不改玩法。

## 消费者

0.2 之后仍能指出来的重复，例如：

- 注册表 `windowColumns/windowRows` 与各游戏 `SetConsole(...)` 各写一份，对不上就会设错窗。
- 某款仍手写 `Sleep(1)` 而其它已走引擎节拍。
- 启动器/引擎里同一段 Win32 设窗逻辑复制两份。

没有第二处、也不在添乱的魔法数 **不要抽**。

## 做 / 不做

| 做 | 不做 |
| --- | --- |
| 合并已出现的双份窗口尺寸或双份节拍 | Game 基类、虚函数玩法框架 |
| 删掉 0.2 之后还活着的 `Sleep(1)` 空转 | 关卡脚本、ini/json 配置体系 |
| 把「只在一处用」的数字留在调用点 | 为未实现游戏预留工厂/插件口 |
