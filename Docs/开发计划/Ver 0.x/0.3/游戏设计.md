# 0.3 游戏设计：硬编码与宿主去重

> **交付目标：启动器与已实现游戏里，正在造成双份真相或仍绕过引擎的硬编码收掉。观感仍是同一台掌机，不改玩法。**

## 1. 做 / 不做

| 做 | 不做 |
| --- | --- |
| 菜单进的游戏 `SetConsole` 用注册表宽高 | Game 基类、虚函数玩法框架 |
| `ClearScreen` 替代 `system("cls")` | 关卡脚本、ini/json |
| 启动器拉起游戏走引擎 `SpawnGameInClassicHost` | 单进程 `RunXxx()` |
| `canResize`：经典 conhost 为 true，并被锁窗路径使用 | 为未实现游戏预留工厂 |

基础版 Tetris / Snack / MazeRoot 不在主菜单，尺寸仍写在本文件，不与注册表抢。
