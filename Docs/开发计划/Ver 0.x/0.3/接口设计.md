# 0.3 接口设计

> 全部 **[已定]**。

## 1. 清屏与按注册表设窗

```cpp
void ClearScreen();
void SetConsoleFromGameId(int id);
```

`SetConsoleFromGameId` 用注册表名称与宽高调用 `SetConsole(..., "80")`。找不到编号则不做事。

## 2. 拉起游戏

```cpp
bool SpawnGameInClassicHost(const wchar_t* exePath, const wchar_t* workDir,
                             int columns, int rows, PROCESS_INFORMATION* out);
```

成功时 `out` 有效，调用方负责关句柄并等待。conhost 不可用则 `CREATE_NEW_CONSOLE` 直接起 exe。

## 3. 终端

`TerminalInfo.canResize`：经典 conhost 为 true，Windows Terminal / 重定向为 false。
