# 0.3 技术设计

接口见 [`接口设计.md`](接口设计.md)。

## 1. 尺寸

主菜单已实现项：`FindGameById` 的 `windowColumns/windowRows` 是唯一来源。游戏 `SetConsole(name, entry->windowColumns, entry->windowRows, "80")`。启动器 `STARTF_USECOUNTCHARS` 仍读同一条目。

## 2. 清屏

`ClearScreen` 用控制台 API 填满缓冲并归位光标，不调 `system("cls")`。

## 3. 宿主

`SpawnGameInClassicHost` 把启动器里的 conhost `--` / `CREATE_NEW_CONSOLE` 回退收进引擎。游戏进程仍自己 `SetConsole`（已有 `BRICK_FIXED_HOST` 防二次弹窗）。

## 4. canResize

`ProbeTerminal`：窗口类是 `ConsoleWindowClass` 则 `canResize = true`。`ApplyConsoleSize` 在 `canResize` 时走锁窗；不能锁时仍尽量 resize，但不假装自己能锁。
