# 0.2 技术设计

> **技术目标：引擎用单调时钟给出整机节拍；启动器把 SPEED 写入子进程环境；已实现游戏循环不再用 Sleep 计数当下落钟。**

接口形状见 [`接口设计.md`](接口设计.md)。

## 1. 技术原则

- `SetConsole` 四参数签名不改。
- 节拍用 `QueryPerformanceCounter`，不跟显示器 vsync。
- `PumpFrame` 短睡（约 8ms）只为让出 CPU 和轮询按键，不充当逻辑钟。
- 探测 / 坐标映射本版不改；单测不测真实睡眠毫秒。

## 2. 分层

```text
brick_launcher     显示 SPEED，s 改档，CreateProcess 前 SetMachineSpeed
游戏 exe           PumpFrame + DueLogicTick + 原 kbhit
brick_engine       Tick.cpp：档位、间隔、PumpFrame、DueLogicTick
```

## 3. 间隔

SPEED 1 = 700ms 一拍，SPEED 10 = 60ms，中间线性。缺省 5。

射击 / 弹球：一次 `DueLogicTick` 等于旧循环一次 `t++`，`t&1` / `t&127` 相对倍率保留。

## 4. 传递

与 `BRICK_FIXED_HOST` 相同：`SetEnvironmentVariableW(L"BRICK_SPEED", L"1"…"10")`，子进程继承。`GetMachineSpeed` 第一次读环境并夹取到 1～10，之后缓存。`SetMachineSpeed` 同时改缓存和环境。

## 5. 测试

| 测 | 不测 |
| --- | --- |
| 夹取 0→1、11→10、缺省 5 | `PumpFrame` 是否真睡了 8ms |
| SPEED 1 的间隔大于 SPEED 10 | 显示器 Hz |
