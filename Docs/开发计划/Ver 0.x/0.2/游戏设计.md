# 0.2 游戏设计：掌机速度

> **交付目标：启动器开局前能选整机 SPEED 1～10；已实现 9 款（含基础版）按这一档走逻辑节拍，不再跟显示器刷新率飞。**
>
> 调研见 [`../../../参考/掌机速度与帧率.md`](../../../参考/掌机速度与帧率.md)。

## 1. 设计原则

- 真机 SPEED 是开机一档，不是每款游戏自己一套键。
- 输入仍可每圈轮询；下落 / 卷轴 / 弹道 / 蛇步只在逻辑拍上发生。
- 迷宫是按键移动，没有下落拍，但仍要 `PumpFrame`，禁止空转占满 CPU。

## 2. 做 / 不做

| 做 | 不做 |
| --- | --- |
| 整机一档 SPEED 1～10，环境变量 `BRICK_SPEED` | 整机 LEVEL |
| `PumpFrame` 替代 `Sleep(1)` / `Sleep(30)` / 迷宫空转 | vsync、帧插值、独立渲染线程 |
| `DueLogicTick` 按 SPEED 映射间隔 | `ITickable`、每游戏曲线表 |
| 射击类一次逻辑拍 = 旧循环一次 `t++`，保留 `t&1` 等相对倍率 | 改碰撞、计分、地图 |

贪吃蛇 Pro：局内 Z 仍可多走一步；选图时上下键不再改 1～5 速度。TetrisPro 不再用分数缩短下落间隔；HUD 显示整机档。

## 3. 流程

```text
启动器显示 SPEED n，输入 s 循环 1～10
  → 拉起游戏前写入 BRICK_SPEED
  → 游戏 GetMachineSpeed，循环 PumpFrame
        DueLogicTick 为真 → 走一步逻辑
        kbhit 处理方向 / 空格暂停
```

## 4. 验收标准

- 启动器能看到当前 SPEED，输入 s 能改 1～10，拉起的游戏读到同一档。
- SPEED 1 的方块 / 蛇明显慢于 10。
- 迷宫不再空转占满 CPU。
- 节拍不随显示器 Hz 变；碰撞、计分、地图仍是旧逻辑。
- 直接双击游戏 exe（无环境变量）时 SPEED 缺省 5。
