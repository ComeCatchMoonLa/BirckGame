# 0.1 接口设计

> 每条标 **[已定]** 或 **[待确认]**。AI 不自行改 [已定]。无未拍的 [待确认] 时可进实现。

## 1. 终端  **[已定]**

```cpp
enum class TerminalKind {
    ConHostLegacy = 0,
    ConHostModern,
    WindowsTerminal,
    UnknownConPTY,
    Redirected
};

struct TerminalInfo {
    TerminalKind kind;
    unsigned osBuild;
    bool vtEnabled;
    bool canResize;
    unsigned inputCp;
    unsigned outputCp;
    int fontWidth;
    int fontHeight;
    int cellColumnsPerBlock;
};

TerminalInfo ProbeTerminal();
int LogicalToColumns(int logicalWidth, int cellColumnsPerBlock);
bool ApplyConsoleSize(int columns, int rows, const TerminalInfo& info);
bool ApplyConsoleColor(const char* color, const TerminalInfo& info);
```

- `cellColumnsPerBlock` 默认 2。小于 1 时 `LogicalToColumns` 按 1 算。
- `ApplyConsoleColor("80")`：灰底黑字，属性 `0x80`。

## 2. 兼容引擎  **[已定]**

`SetConsole` 的 width/height 是控制台列、行。每个游戏用自己的值，不是启动器的 80xN。

## 3. 注册表  **[已定]**

GameEntry 含 windowColumns / windowRows，与该游戏 SetConsole 一致：贪吃蛇 80x30，俄罗斯方块 40x27，赛车 30x30。未实现为 0。数量以游戏列表为准（当前 88 款，含变体）。

## 4. 启动器  **[已定]**

- 已实现：CreateProcess 经 conhost 开独立经典控制台（与菜单分离，禁止拉伸/最大化）。conhost 不可用时退回 CREATE_NEW_CONSOLE。仍带 STARTF_USECOUNTCHARS。
- SetConsole 设窗后去掉 WS_THICKFRAME / WS_MAXIMIZEBOX。若游戏被 Windows Terminal 托管，会换到 conhost 再跑。
- 未实现：提示未实现。
- 启动器三列菜单；高度按 (GetGameCount()+2)/3 + 6。未实现项标 *。
