# 0.x 大纲

> **0.x 把引擎做稳，不填新游戏。** 1.x 才按清单往菜单里加未实现项。1.0 的门槛仍是清单全部都能进，不是先做联机或跨平台。

| 版本 | 边界 | 消费者 | 状态 |
| --- | --- | --- | --- |
| 0.1 | 终端探测、CMake、启动器、旧 9 款进菜单 | 启动器 + 已有 exe | 壳已实现，手测见 0.1 TODO |
| 0.2 | 整机 SPEED 节拍 | 启动器选档；9 款 `Sleep(1)` 循环 | 仅游戏设计大纲 |
| 0.3 | 硬编码优化 | 已在痛的重复：双份窗口尺寸、未改掉的 Sleep、魔法数 | 仅游戏设计大纲 |
| 0.4～0.x | 其它引擎债 | 必须先写出谁在用 | 不预列 |

## 约束

- 新 API / 新抽象：当前切片里至少有一处启动器或已实现游戏要调用。没有消费者就不要做。
- 不为未实现游戏预留原语、空文件夹、基类、插件口。
- 0.x 不做：跨平台、音频、网络、双缓冲框架、把旧游戏收成单进程 `RunXxx()`。
- 未实现玩法（青蛙过河起）→ 1.x。
