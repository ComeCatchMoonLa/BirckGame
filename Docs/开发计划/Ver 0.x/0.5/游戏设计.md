# 0.5 游戏设计：积分存档

> **交付目标：每款已实现游戏记住一条最高分（HI-SCORE）；启动器能看。不设昵称，榜上只有数字。**

## 1. 做 / 不做

| 做 | 不做 |
| --- | --- |
| 每游戏一条最高分 | 昵称、改名、多用户、前三名 |
| 局结束时写入（Game Over / 通关 / 被击中） | Esc 中途退出也记一笔 |
| 启动器输入 h 看已实现游戏的榜 | 未实现游戏占空行 |
| 文件与启动器、游戏 exe 同目录 | 云存档、加密、设置页 |

## 2. 积分含义（越高越好）

| # | 游戏 | 积分 |
| --- | --- | --- |
| 1 | 俄罗斯方块 | 已有消行 score |
| 2 | 贪吃蛇 | 已有食物 Score |
| 3 | 消除射击 | 打掉的墙数 |
| 4 | 填补射击 | 消除的整行数 |
| 5 | 淘气方块 | 已有对齐 score |
| 6 | 寸步难行 | 被球碰到前的存活拍数 |
| 7 | 方块赛车 | 存活逻辑拍数 |
| 17 | 迷宫 | max(1, 10000 - 玩家前进步数) |

基础版 Tetris / Snack / MazeRoot 不在主菜单，不写榜。

## 3. 验收

- 同一游戏打出更高分才改纪录；同分或更低不改。
- 启动器 h 只显示积分，没有名字栏。
- 关启动器再开，最高分还在。
