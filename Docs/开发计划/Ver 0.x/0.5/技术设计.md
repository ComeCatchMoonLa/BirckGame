# 0.5 技术设计

> **技术目标：引擎读写同目录 brick_scores.txt；游戏只在局结调用 SubmitScore；启动器只读榜。**

接口形状见 [接口设计.md](接口设计.md)。

## 1. 分层

```text
brick_launcher     h 列出已实现游戏 LoadScoreboard
游戏 exe           局结 SubmitScore(id, n)
brick_engine       Scores.cpp：一条最高分、读写文件
```

## 2. 文件

- 路径：当前 exe 所在目录 brick_scores.txt（启动器与游戏都在 build/bin）。
- 文本、UTF-8：首行 `# brick-scores 1`，之后每行 `id score`。旧文件若有多列，只取第一列（最高分）。
- 先写 .tmp 再 MoveFileEx 替换。缺文件视为空榜。
- 无昵称字段；解析时忽略多余列。

## 3. 插入

- 分数小于 0 记 0。
- 未实现 / 非法 id 不写入。
- 已有纪录且新分不超过现纪录：不改文件。
- 并列：必须严格大于才替换。
