# 开发计划

> **本文件夹是按版本推进的唯一入口。** 一个小版本 = 一条能独立验收的边界。
>
> **0.x 引擎（0.1～0.5）已落地；1.1～1.3 已落地并手测。1.4～1.14 待人工核实。** 新引擎能力必须有当前消费者；没有第二处调用的接口不要先抽。0.6 起有消费者才开，不预列。

规则事实以 [`../机制研究.md`](../机制研究.md)、[`../终端与控制台调研.md`](../终端与控制台调研.md)、[`../参考/游戏清单对照.md`](../参考/游戏清单对照.md)、[`../参考/掌机速度与帧率.md`](../参考/掌机速度与帧率.md) 为准。

## 1. 版本号

两段式 `主.次`，不做补丁号。

| 版本段 | 含义 |
| --- | --- |
| **0.1** | 终端探测 + 启动器 + 旧游戏进菜单（壳） |
| **0.2** | 整机 SPEED 节拍 |
| **0.3** | 硬编码与宿主去重 |
| **0.4** | 游戏可退回菜单 |
| **0.5** | 每游戏一条最高分 |
| **0.6～0.x** | 有消费者才开，不预列 |
| **1.1～1.14** | 按系列补未实现游戏（见 [Ver 1.x](Ver%201.x/README.md)） |
| **1.0** | 清单 88 款均可从菜单进入（里程碑，不是第一刀） |

小版本完成：0.x 看该版 TODO 与验收；1.x 看该版编号能进菜单且需求对上。

## 2. 细化深度

- **0.x**：已为 0.1～0.5 写四件套，保留不删。
- **1.x**：不写 TODO / 游戏设计 / 技术设计 / 接口设计。只有大纲 + 需求试卷。实现时读需求，含糊处联网核对同名小品。

## 3. 路线总览

```text
0.1 引擎探测 + 启动器 + 旧游戏进菜单     <- 已落地
0.2 掌机速度                             <- 已落地
0.3 硬编码与宿主去重                     <- 已落地
0.4 退出回菜单                           <- 已落地
0.5 一条最高分                           <- 已落地
0.6～0.x 其它引擎债（有消费者才开，不预列）
1.1～1.3 蛇 / 方块变体                   <- 已落地并手测
1.4～1.14 其余玩法                       <- 待人工核实
1.0 清单全部均可进入
```
