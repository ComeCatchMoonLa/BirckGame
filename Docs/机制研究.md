# 机制研究

> **结论：这是「一机多游戏」的控制台掌机，不是单一 Arcade。** 0.x 把壳和终端做对；菜单已实现 1～7、17。1.1～1.3 又落地 17 个蛇/方块变体。共同需求仍是网格、按键、帧循环、结束重开。

对照源码，不靠记忆。清单原文见 [`../BrickGame/游戏列表.txt`](../BrickGame/游戏列表.txt)，进度见 [`参考/游戏清单对照.md`](参考/游戏清单对照.md)。

## 1. 掌机模型

| 玩家看到的 | 本仓库对应 |
| --- | --- |
| 开机进选关 | 启动器菜单，编号 1～N |
| 选一款进入 | `CreateProcess` 对应 exe |
| 退出回选关 | Esc → `QuitToLauncher`；子进程结束，启动器重画菜单 |
| 未收录的卡带 | 菜单显示「未实现」，不建空工程 |

列表里的「0. 引擎」是基础设施，不是可玩游戏。

## 2. 0.x 原作（源码事实）

| # | 游戏 | 源码要点 | 窗口调用 |
| --- | --- | --- | --- |
| 1 | 俄罗斯方块 | 主菜单 `TetrisPro`：14×24 板。基础版 `Tetris`：20×27、19 种旋转姿态。空格暂停；Game Over 后 `run()` 重开 | Pro `40, 27` |
| 2 | 贪吃蛇 | 主菜单 `SnackPro`：选图 40×26（y 从 4 起）；Z 加速 | Pro `80, 30`；基础版 `80, 25` |
| 3 | 消除射击 | 25×30；墙下移；玩家子弹消墙；敌弹致死 | `50, 30` |
| 4 | 填补射击 | 15×20；子弹撞墙变成墙 | `30, 20` |
| 5 | 淘气方块 | 底部三块对齐下落目标三块 | `80, 30` |
| 6 | 寸步难行 | 160×120 逻辑格；多弹球；玩家 8×8 | `320, 120`（全角方块占两列；仅此游戏用 MS Gothic 常规字重） |
| 7 | 方块赛车 | 15×30；路宽 5；出道 Game Over | `30, 30` |
| 17 | 迷宫 | DFS 挖墙；One 有敌人 AI | `col << 1, row`（显式列数） |

1.1～1.3 变体共用 `SnackCore.h` / `TetrisCore.h`，窗口走 `SetConsoleFromGameId`。exe 名与列数见 [游戏清单对照.md](参考/游戏清单对照.md)。

共同约定：

- `SetPos(x, y)` 的 `x` 是逻辑格，引擎按探测到的 `cellColumnsPerBlock` 映射（全角 `■` 通常 2 列）。
- `SetConsole` 的 width **已经是列数**。新游戏用 `SetConsoleFromGameId`，列行以注册表为准。
- 输入：`kbhit` + `getch`，方向键扫描码 72/80/75/77。
- 结束：多数 `Pause()` 等空格后递归 `run()`。Esc（27）→ `QuitToLauncher`（0.4）。局结更高分才 `SubmitScore`（0.5）。

**0.x 不为它们加原语。** 缺的是游戏状态机，不是第二套引擎。不做伪 3D / 射线。

## 4. 对 0.x 的含义

- **0.1** 边界：探测终端 → 设窗 → 菜单能进已实现游戏。
- **0.2** 整机 SPEED 节拍；**0.3** 清屏 / 尺寸 / 宿主去重；**0.4** Esc 退回菜单；**0.5** 每游戏一条最高分。均已落地。
- 0.x 切片只改启动器和当时已实现原作已经用到的路径。1.x 变体复用同一套 API，不新开时钟。
- 旧游戏能跑曾经靠 conhost 上 `mode con` + 双宽格；终端升级后那条路径会失效，所以壳必须走引擎。

## 5. 引擎能力表

「预留」只写在本表。头文件里没有消费者的符号不要加。

### 已有（0.1）

- `SetConsole` / `SetPos` / `FillStr` / `FillRec` / `FillArea` / `Pause`
- 终端探测、列映射、锁 conhost、注册表、启动器菜单
- `SetCellColumnsPerBlock` / `SetConsoleFontForGrid`（仅寸步难行）

### 0.2～0.5 已落地

| 版本 | 能力 | 消费者 |
| --- | --- | --- |
| 0.2 | `GetMachineSpeed` / `SetMachineSpeed` / `PumpFrame` / `DueLogicTick` / `TakeLogicSteps` | 启动器选档；已实现游戏循环（含 1.1～1.3） |
| 0.3 | `ClearScreen`；窗口尺寸以注册表为准；`SpawnGameInClassicHost`；`canResize` 反映能否锁窗 | 启动器 + 已实现游戏 `cls` / `SetConsole` |
| 0.4 | Esc（27）→ `QuitToLauncher` | 启动器要等进程结束 |
| 0.5 | 每游戏一条最高分，无昵称 | 启动器 h；局结 `SubmitScore` |

1.x 新游戏复用同一套节拍和退出键，不为它们设计第二套时钟。

### 代码不加（直到某款 1.x 真卡住）

- `ITickable`、游戏基类、插件工厂、双缓冲、逐格着色、LEVEL、鼠标、音效、棋盘规则引擎、伪 3D / 射线
- 围棋棋盘规模未拍，进该号再写
