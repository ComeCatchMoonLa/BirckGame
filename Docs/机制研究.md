# 机制研究

> **结论：这是「一机多游戏」的控制台掌机，不是单一 Arcade。** 已有 9 款各自 `main()` + `#include BrickEngine.h`；共同需求是网格、按键、帧循环、结束重开。0.1 只把壳和终端做对，不改各游戏内部规则。

对照源码，不靠记忆。清单原文见 [`../BrickGame/游戏列表.txt`](../BrickGame/游戏列表.txt)，TODO 见 [`参考/游戏清单对照.md`](参考/游戏清单对照.md)。

## 1. 掌机模型

| 玩家看到的 | 本仓库对应 |
| --- | --- |
| 开机进选关 | 启动器菜单，编号 1～N |
| 选一款进入 | `CreateProcess` 对应 exe |
| 退出回选关 | 子进程结束，启动器重画菜单 |
| 未收录的卡带 | 菜单显示「未实现」，不建空工程 |

列表里的「0. 引擎」是基础设施，不是可玩游戏。

## 2. 已实现 9 款（源码事实）

| # | 游戏 | 源码要点 | 窗口调用 |
| --- | --- | --- | --- |
| 1 | 俄罗斯方块 | 20×27 板；19 种旋转姿态；空格暂停；Game Over 后 `run()` 重开 | `SetConsole(..., 40, 27, "80")` |
| 2 | 贪吃蛇 | 逻辑 40×25；方向 0/1/2/3；Z 加速 | `80, 25`；Pro 为 `80, 30` 且读 `Map.h` |
| 3 | 消除射击 | 25×30；墙下移；玩家子弹消墙；敌弹致死 | `50, 30` |
| 4 | 填补射击 | 15×20；子弹撞墙变成墙 | `30, 20` |
| 5 | 淘气方块 | 底部三块对齐下落目标三块 | `80, 30` |
| 6 | 寸步难行 | 160×120 逻辑格；多弹球；玩家 8×8 | `320, 120`（列数已加倍） |
| 7 | 方块赛车 | 15×30；路宽 5；出道 Game Over | `30, 30` |
| 17 | 迷宫 | DFS 挖墙；One 有敌人 AI | `col << 1, row`（显式列数） |

共同约定：

- `SetPos(x, y)` 的 `x` 是逻辑格，引擎里 `x << 1` 映射到列（全角 `■`）。
- `SetConsole` 的 width **已经是列数**，各游戏自己换算，互不一致的是「谁在调用处加倍」，不是引擎再加倍。
- 输入：`kbhit` + `getch`，方向键扫描码 72/80/75/77。
- 结束：多数 `Pause()` 等空格后递归 `run()`，进程不退出。启动器要回菜单，玩家需关窗口或以后版本再加退出键。

## 3. 未实现项对引擎的共同需求

| 品类 | 编号 | 0.1 引擎是否已够 |
| --- | --- | --- |
| 过马路 / 接物 / 跳 | 8、11、22 | 网格 + 帧循环 + 碰撞，现 API 够 |
| 弹球 / 射击 / 挡板 | 9、10、14、20、28～30 | 现 API 够 |
| 迷宫格 | 21、23 | 现 API 够 |
| 解谜 / 翻面 | 12、13、15、16、18、19、32～35 | 现 API 够 |
| 棋类 | 24～27 | 回合制；现 API 够 |
| 反应 | 31 | 现 API 够 |

36～88 是变体和小品（镜像方块、穿墙蛇、三格 2048 等），与上表同类，现 API 够。**不单独写游戏设计**，1.x 做某一号时再写该号三件套。

**0.x 不为它们加原语。** 缺的是游戏状态机，不是第二套引擎。未实现玩法放到 1.x。不做伪 3D / 射线。

## 4. 对 0.x 的含义

- **0.1** 边界：探测终端 → 设窗口 → 菜单能进已实现游戏。
- **0.2** 整机 SPEED 节拍；**0.3** 清屏 / 尺寸 / 宿主去重；**0.4** Esc 退回菜单；**0.5** 每游戏一条最高分。
- 只改启动器和已实现 9 款已经用到的路径。
- 旧游戏能跑曾经靠 conhost 上 `mode con` + 双宽格；终端升级后那条路径会失效，所以壳必须走引擎。

## 5. 引擎能力表

「预留」只写在本表。头文件里没有消费者的符号不要加。

### 已有（0.1）

- `SetConsole` / `SetPos` / `FillStr` / `FillRec` / `FillArea` / `Pause`
- 终端探测、列映射、锁 conhost、注册表、启动器菜单

### 0.2～0.5 要加（已有消费者）

| 版本 | 能力 | 消费者 |
| --- | --- | --- |
| 0.2 | `GetMachineSpeed` / `SetMachineSpeed` / `PumpFrame` / `DueLogicTick` | 启动器选档；9 款循环 |
| 0.3 | `ClearScreen`；窗口尺寸以注册表为准；`SpawnGameInClassicHost`；`canResize` 反映能否锁窗 | 启动器 + 9 款 `cls` / `SetConsole` |
| 0.4 | Esc（27）→ `QuitToLauncher` | 启动器要等进程结束 |
| 0.5 | 每游戏一条最高分，无昵称 | 启动器 h；8 款局结 |

1.x 新游戏复用同一套节拍和退出键，不为它们设计第二套时钟。

### 代码不加（直到某款 1.x 真卡住）

- `ITickable`、游戏基类、插件工厂、双缓冲、逐格着色、LEVEL、鼠标、音效、棋盘规则引擎、伪 3D / 射线
- 围棋棋盘规模未拍，进该号再写
