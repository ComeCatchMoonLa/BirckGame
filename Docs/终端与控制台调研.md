# 终端与控制台调研

> **结论：按每个游戏自己的 cols/lines 设缓冲宽度。** 贪吃蛇地图按一行 80 列换行，不能沿用启动器或 Windows Terminal 默认宽高比。

## 设窗顺序

1. 打开 VT。
2. VT CSI 8 ; rows ; cols t。
3. SetConsoleScreenBufferSize + SetConsoleWindowInfo，以缓冲宽度是否等于请求列为准。
4. 仍不对再 mode con。
5. 颜色：VT SGR -> SetConsoleTextAttribute -> color。

## 宽度语义

SetConsole 的 width 是列数。Tetris 40、SnackPro 80、Racing 30x30。SetPos 的 x 是逻辑格。

## 禁止拉伸

Windows Terminal 拉窗口会改 PTY 列数，按固定列画的地图就会乱。游戏用 conhost 开独立窗，并去掉拉伸框与最大化。启动器自身可以留在 WT 里。
